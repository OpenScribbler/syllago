## v0.14.0

### Highlights

**Leaner, CGO-free builds.** The capability-monitor tooling moved to its own
repository, [OpenScribbler/capmon](https://github.com/OpenScribbler/capmon),
taking the headless-Chrome and tree-sitter dependencies with it. Building
syllago no longer requires CGO, and the dependency graph is substantially
smaller.

**Security refresh.** The Go toolchain moved to 1.26.5 and the signing stack
picked up patched releases of sigstore/rekor, timestamp-authority, and
x/crypto, addressing several upstream security advisories.

**Two canonical metadata keys graduated.** `auto_invocable` and
`skill_bundled_resources` are now stable canonical keys in
`docs/spec/canonical-keys.yaml`.

---

### Changed

- **`syllago capmon` is now the standalone `capmon` tool.** The full
  capability-monitor command tree (`run`, `fetch`, `verify`, `check`,
  `seed`, `generate`, and the validators) lives in
  [OpenScribbler/capmon](https://github.com/OpenScribbler/capmon) with the
  same subcommands and flags. The provider capability data under `docs/`
  stays in this repository, and the monitor continues to open pull requests
  and issues here when provider documentation drifts. The `provider-monitor`
  helper binary moved to the same repository.
- **Placeholder commands removed.** `refresh`, `sign`, `verify`, and
  `export` only ever printed "not yet implemented" and are gone. Content
  signing remains available through `syllago moat sign`.

### Security

- Go toolchain 1.26.3 → 1.26.5.
- `sigstore/rekor` → v1.5.2, `timestamp-authority` → v2.1.0,
  `golang.org/x/crypto` → v0.54.0.
- The `govulncheck` CI gate documents a single allowlisted advisory
  (`x/crypto/openpgp`, which has no fixed release and is reachable only
  through rekor's entry-type registry); everything else still fails the
  build.

### Improvements

- **Smaller, faster codebase.** A repository-wide cleanup removed about
  39,000 lines: dead packages and stub commands are gone, and roughly 30
  families of copy-pasted parsing, rendering, and UI plumbing now share
  single helpers. Behavior is pinned by the existing test suites — CLI
  output and TUI rendering are byte-identical.
- Continuous integration runs meaningfully faster: the capability-monitor
  test suite no longer runs in this repository, and the redundant non-race
  test pass was dropped.
