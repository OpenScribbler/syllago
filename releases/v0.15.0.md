## v0.15.0

### Highlights

**See what changed upstream** — `registry sync` now lists the items a sync
added, changed, or removed and flags installed items that drifted. The new
`syllago registry status` shows pending changes without syncing.

**Pin and roll back registry content** — `syllago pin` holds an installed
registry item at its current content, and `syllago rollback` restores the
version you had before the last update, from the CLI or the TUI.

**Windsurf is now Devin Desktop** — The provider slug is `devin`, your library
migrates automatically, and Devin Desktop gains agent support and working
hook installs.

---

### New Features

#### Registries

- **Change reports on sync**: `registry sync` prints `+`/`~`/`-` lines per
  changed item, with recent upstream commit subjects for git registries. TUI
  sync toasts show the counts.
- **`syllago registry status [name]`**: Compares upstream against your last
  sync without moving the checkout or writing any cache. Supports `--json`.
- **Installed-item drift**: After a sync, syllago lists installed items whose
  upstream content changed or disappeared, with the command to refresh or
  remove each one.
- **Pinned registries**: `registry add --ref` now works with tags and commit
  SHAs. A tag or commit ref pins the registry: sync fetches but never moves
  the checkout. `registry list` gains a `REF` column with a `(pinned)` marker.

#### Pinning and rollback

- **`syllago pin <name>` / `syllago unpin <name>`**: Hold a registry item at
  its current content. Re-adds and registry installs of a pinned item are
  refused until you unpin it.
- **`--frozen`**: Pins the install record that `install` or
  `add --install --to` creates.
- **`syllago rollback <name>`**: Restores the previous version of a
  registry-sourced item and re-applies its hook and MCP installs. Supports
  `--dry-run`.
- **TUI**: `p` toggles pin and `z` rolls back (with confirmation) in the
  Library and Explorer, with matching buttons and a `Pinned @<sha>` chip.

#### Install tracking and doctor

- **Install records**: Every install, uninstall, and remove is recorded in
  `~/.syllago/installs.json` with a content hash.
- **`syllago doctor` checks real provider directories**: It finds broken links
  and unrecorded installs, adds a `trust` check for stale signing material and
  registry caches, and warns about near-duplicate registries.
- **`doctor --fix`**: Shows a plan, then relinks or prunes broken links and
  records untracked installs.
- **Registry installs go through your library**: `syllago install
  <registry>/<item>` copies verified content into your library first.

#### Providers

- **Devin Desktop agents**: Agents install to `~/.config/devin/agents/`
  (`%APPDATA%\devin\agents\` on Windows), with `tools` mapped to Devin's
  `allowed-tools`. Devin's `max-nesting` is dropped on import with a warning.
- **Devin Desktop hooks**: `syllago install --to devin` merges hooks into
  `~/.config/devin/config.json` (`%APPDATA%\devin\config.json` on Windows)
  and leaves its other settings alone; earlier releases refused. Hooks use
  Devin's current events (`PreToolUse`, `PostToolUse`, `UserPromptSubmit`,
  and others) and tool names, and `syllago convert` emits the same format.
  Convert also reads a bare `.devin/hooks.v1.json` and drops fields Devin
  doesn't support (`async`, `statusMessage`) with a warning. Hooks on
  worktree-setup or transcript events, which Devin dropped, are skipped with
  a warning.
- **Crush hooks**: Hooks install into `crush.json`.
- **Zed skills**: Skills install to `.agents/skills/`, where Zed reads them.
- **Copilot CLI, Kiro, and pi hooks**: Hooks install to a file syllago owns
  in each tool's home directory, leaving your own files alone. The pi
  extension now uses pi's real extension API.

#### Claude Code plugins

- **`syllago list` shows Claude Code plugins**: Enabled plugins appear in
  their own section (`--source plugin` for only them), with a warning when a
  plugin skill shares a library skill's name. Syllago does not change
  plugins.

### Improvements

- **Windsurf provider renamed to Devin Desktop (slug `devin`).** The
  `windsurf` slug is deprecated: it still works in flags, config files, and
  loadouts with a warning, and will be removed in a future release. The first
  command after upgrading moves library `windsurf/` folders to `devin/`,
  leaving a link at the old path. Global skills now install to
  `~/.config/devin/skills/`; Devin Desktop's other paths are unchanged.
- **Install paths come from published ACIF data**, fetched when online with
  a bundled fallback, and resolved per operating system.

### Security

- **Sigstore trusted root refreshed** (issued 2026-10-01). It adds Sigstore's
  Rekor v2 log (`log2025-1.rekor.sigstore.dev`) and timestamp authority URL.
  The "bundled Sigstore trusted root is N days old" warning that v0.14.0
  prints on every signed-registry operation goes away after upgrading.
- Publishing a loadout to a public registry now catches references to private
  content in multi-provider loadouts and single-file items.
- `syllago remove` deletes only provider links that resolve into the item
  being removed, and stops before deleting library content if link cleanup
  fails.
- Go 1.26.6 (standard-library security fixes); `sigstore-go` v1.3.0,
  `sigstore` v1.10.9, `rekor` v1.5.3, `grpc` v1.83.2.

### Bug Fixes

- Fixed hook installs writing Claude Code-shaped entries for Cursor, Gemini
  CLI, Factory Droid, and Crush. Hooks now use each provider's format and keep
  the file's other settings.
- Fixed hook matchers keeping syllago's tool names (`shell`) instead of the
  provider's (`Bash`), so the hook never fired.
- Fixed hooks with a list of tool matchers firing on every tool in Claude
  Code, Gemini CLI, Factory Droid, and Devin Desktop. The list now becomes a
  regex alternation (`Bash|Write`).
- Fixed install writing hooks for events the provider can't read; it now
  refuses them.
- Fixed agents installing in syllago's own format for every provider. They
  now install rendered for the target; Codex agents go to `~/.codex/agents/`.
- Fixed CLI hook and MCP installs for Cursor, Kiro, OpenCode, Roo Code, and
  Copilot CLI landing under `~/.syllago/content/` instead of the project.
- Fixed `doctor` reporting a stale MOAT cache after a successful sync when
  the project sets `content_root`.
- Fixed MOAT manifests being rejected over an unknown revocation reason.
- Fixed `convert` writing an empty frontmatter block and failing on agents
  added from OpenCode.

### Build & Infrastructure

- Provider capability data in `docs/` is mirrored daily from capmon's signed
  Capability Feed (now v2).
- Syllago passes all ten scopes of the ACIF conformance suite.
- Routine dependency and GitHub Actions bumps.

### Breaking Changes

- **`registry add` no longer clones**: It registers the registry and the
  first `registry sync` clones it. Migration: `syllago registry add --sync`.
- **Loadouts with unsupported hooks fail to apply**: A loadout with a hook the
  provider can't read now fails instead of partly applying. Migration:
  `syllago loadout apply --skip-unsupported`.
