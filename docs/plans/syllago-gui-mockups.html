name: code-review
description: Structured diff review with severity-ranked findings
version: 1.4.2

Code Review

Review the working diff for correctness bugs and simplification opportunities. Findings are ranked by severity and each one is adversarially verified before being reported.

Process

Collect the diff with scripts/collect-diff.sh, then review each hunk against the severity rubric:

1. Correctness  — wrong output, crash, data loss
2. Security     — injection, secret exposure, authz gaps
3. Simplify     — dead code, needless abstraction
4. Efficiency   — avoidable allocations, N+1 queries

Reporting

Each finding names the file and line, states the defect in one sentence, and describes the concrete failure scenario. Findings that don’t survive verification are dropped, not hedged.
